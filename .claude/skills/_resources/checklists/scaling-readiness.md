# Scaling Readiness Checklist

## Pre-Requisites for Scaling

### Stable Performance

- [ ] Consistent ROAS for 3+ days
- [ ] Stable CPA (variation < 20%)
- [ ] Minimum volume of 50 conversions/week
- [ ] CTR above 1% (average)
- [ ] Frequency below 2.5

### Validated Creatives

- [ ] At least 2 "winner" creatives identified
- [ ] Winners with 1000+ impressions each
- [ ] Consistent performance (not a one-hit wonder)
- [ ] New creatives in testing (active pipeline)

### Tested Audiences

- [ ] Most profitable tier identified
- [ ] Lookalikes tested (1%, 2%, 3%)
- [ ] Broad interests tested
- [ ] Audiences not saturated (frequency OK)

### Infrastructure

- [ ] Tracking 100% functional
- [ ] CAPI match rate > 80%
- [ ] Landing page can handle more traffic
- [ ] Checkout scales (no bottlenecks)
- [ ] Customer support prepared

## Types of Scaling

### Vertical Scaling (Same Ad Set)

**When to use:** Clear winner, want to preserve learning-phase data

- [ ] Increase max 20-30% per day
- [ ] Wait 24-48h between increases
- [ ] Monitor CPA after each increase
- [ ] Have a fallback if CPA rises

**Criteria:**
| Metric | Minimum |
|---------|--------|
| ROAS | 2x+ consistent |
| Conversions | 10+/day in the ad set |
| Phase | Out of learning phase |

### Horizontal Scaling (Duplication)

**When to use:** Testing variations, diversifying risk

- [ ] Duplicate the winning ad set
- [ ] Keep budget equal to the original
- [ ] Test a new audience or creative
- [ ] Don't duplicate more than 3x

**Criteria:**
| Metric | Minimum |
|---------|--------|
| ROAS | 1.5x+ consistent |
| Data | 500+ impressions |
| Trend | Stable or growing |

### CBO (Campaign Budget Optimization)

**When to use:** Multiple winners, want automation

- [ ] Minimum 3 validated ad sets
- [ ] All with positive ROAS
- [ ] Migrate to CBO with total budget
- [ ] Monitor budget distribution

**Criteria:**
| Metric | Minimum |
|---------|--------|
| Ad sets | 3+ validated |
| Average ROAS | 2x+ |
| Variation | < 30% between ad sets |

## Warning Signs During Scaling

### Stop Immediately ❌

- CPA doubled after 48h
- CTR dropped more than 50%
- Frequency above 4
- Negative ROAS for 3 days

### Caution ⚠️

- CPA rose 30-50%
- Frequency rising fast
- CPM increasing
- Fewer conversions proportionally

### Continue ✅

- Stable CPA (variation < 20%)
- Volume increasing proportionally
- Frequency under control
- ROAS holding or improving
