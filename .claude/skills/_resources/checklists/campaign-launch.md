# Campaign Launch Checklist

## Pre-Launch

### Tracking & Pixel

- [ ] Pixel installed and firing PageView
- [ ] Events configured (VC, ATC, IC, Purchase/Lead)
- [ ] CAPI active and working
- [ ] Match rate above 80%
- [ ] Event test performed via Events Manager

### Sales Page

- [ ] URL loading correctly
- [ ] Checkout working (test purchase)
- [ ] Mobile responsiveness verified
- [ ] Speed < 3s (PageSpeed)
- [ ] No console errors

### Creatives

- [ ] Minimum 3 creatives approved
- [ ] Correct formats (1:1, 9:16)
- [ ] Captions/subtitles included
- [ ] Copy variations ready (3x)
- [ ] Headlines ready (3x)

### Audiences

- [ ] Audiences created and saved
- [ ] HOT: Recent buyers/leads
- [ ] WARM: Engaged + Visitors
- [ ] COLD: Interests + Lookalikes
- [ ] Adequate sizes (not too small)

### Campaign

- [ ] Correct objective selected
- [ ] Optimized for the right event
- [ ] Initial budget set
- [ ] Bid strategy configured
- [ ] Placements reviewed

---

## At Launch

### Final Setup

- [ ] Campaign name standardized
- [ ] UTMs configured
- [ ] Correct attribution (7-day click, 1-day view)
- [ ] Adequate conversion window
- [ ] Spend limits verified

### Validation

- [ ] Ad previews reviewed
- [ ] Links tested in previews
- [ ] Meta policies checked
- [ ] Budget released on the account

### Publishing

- [ ] Campaign activated
- [ ] Launch time logged
- [ ] Screenshot of structure saved
- [ ] Monitoring alert configured

---

## Post-Launch (First 24h)

### Initial Monitoring

- [ ] Campaign approved (not rejected)
- [ ] Impressions being delivered
- [ ] Events being logged
- [ ] No delivery errors

### Initial Metrics (after 1000 impressions)

- [ ] CTR within expected range (>0.5%)
- [ ] CPM within benchmark
- [ ] Cost per event reasonable
- [ ] Distribution across ad sets OK

### Documentation

- [ ] Ads Manager screenshot saved
- [ ] Initial metrics logged
- [ ] Observations documented
- [ ] Next review scheduled

---

## Go/No-Go Criteria

### GO (Can launch)

✅ All tracking items verified
✅ At least 3 creatives ready
✅ Page working 100%
✅ Budget approved

### NO-GO (Don't launch)

❌ Pixel not firing events
❌ CAPI not configured
❌ Checkout broken
❌ Fewer than 2 creatives
