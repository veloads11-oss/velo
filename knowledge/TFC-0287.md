# Challenge Funnel Economics

## TL;DR (Heuristic)
Challenge funnels: $200K+ ad budget, 8 weeks, 1.5-2.5x front ROAS, 5-15x total ROAS. Paid = 70% show rate.

## Quick Guide
> Golden rule: "The front-end pays for the ads, the back-end is the profit"

### Pre-Challenge Checklist
- [ ] Minimum $200K budget confirmed?
- [ ] 8 weeks of runway?
- [ ] OTOs configured (3 tiers)?
- [ ] Main offer ready ($5K-$25K)?

---

## Detailed Framework (Analytical)

### Case Study $4M
| Metric | Value |
|---------|-------|
| Ad spend | $292K |
| Tickets | $554K (1.9x) |
| Registrations | 6,000+ |
| Show rate | 70% |
| Challenge rev | $3.4M |
| Main offer | $10K |

### Target Metrics
| Metric | Target | Acceptable | Bad |
|---------|--------|-----------|------|
| CPR | $15-30 | $30-50 | >$50 |
| Show Rate | >70% | 50-70% | <50% |
| Conversion | 10-15% | 5-10% | <5% |
| Front ROAS | 2x+ | 1.5-2x | <1.5x |
| Total ROAS | 10x+ | 5-10x | <5x |

### OTO Structure
```
OTO1: $100-150 → 15% CVR
OTO2: $200-300 → 10% CVR
OTO3: $400-600 → 7% CVR
ADDITIONAL TOTAL: ~$80/registrant
```

---

## Patterns and Insights (Intuitive)

### Main Analogy
> "A challenge funnel is like a rock show - you sell cheap tickets to pack the venue, and you profit on the beer and t-shirts (back-end)"

### Recognizable Patterns
- If front ROAS > 2x, scale aggressively
- If show rate < 50%, the problem is in the pre-event
- If conversion < 5%, the pitch or offer needs adjustment

---

## Pitfalls and Mistakes (Critical)

### Red Flags
- If ad budget < $100K, DO NOT run a challenge
- Never launch without 8 weeks of promotion
- If show rate < 40%, pause and fix it

### Common Mistakes
```
MISTAKE: Calculating ROAS only on the front-end
FIX: Always calculate total ROAS (front + main offer)

MISTAKE: Free challenge for a cold audience
FIX: Run a paid challenge or warm up the audience first
```

## Variations (Creative)

## Key Points
- Minimum $200K ad budget
- 8 weeks of promotion
- Paid > Free (70% vs 30% show)
- Front-end = break-even, back-end = profit
