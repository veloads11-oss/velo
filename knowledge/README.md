# Knowledge Base — Read This First

517 knowledge chunks (`TFC-XXXX.md`) backing the Traffic Command squad
(`.claude/agents/`). Originally sourced from a Brazilian Portuguese-language
Meta ads media-buying course; translated to English and adapted for Velo
(Canada, CAD) from that source.

## Caveats

- **Currency**: any advertising benchmark figures (CPM/CPC/CPA/ROAS
  targets presented as market standards) that were originally in
  Brazilian Real (R$) were replaced with `[TBD — CAD]` rather than
  guessed — ad costs don't convert by exchange rate, they're set by
  local auction competition. Fill these in from Hussein's real campaign
  data via `scripts/report.py` as it accumulates. Generic worked
  examples/template placeholders were left as direct CAD$ symbol swaps
  since they aren't market-specific claims.
- **Quality varies.** Some chunks are tight, actionable frameworks;
  others are raw motivational video transcripts with low reusable
  content. Don't treat every chunk as equally authoritative — use
  judgment on what's actually a framework vs. filler.
- **Third-party sourced.** This content is derived from named paid
  marketing courses/experts (anonymized as "Expert Source A/B/C" etc. in
  places). It's for Velo's internal reference use, not for
  redistribution or resale.

See `_DIR_INDEX.md` for chunk format and range.
