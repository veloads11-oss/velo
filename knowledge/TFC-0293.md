# Challenge Ad Strategy

## TL;DR (Heuristic)
4 creative frameworks, 3 audience tiers, test 5-10 concepts, scale winners 20-30%/week.

## Quick Guide
> Golden rule: "CPR target $15-30, kill losers within 3 days"

### Ads Checklist
- [ ] 5+ creative concepts?
- [ ] Warm + LAL + Cold separated?
- [ ] Budget per ad set $100-500/day?
- [ ] Metric = CPP (cost per purchase)?

---

## Detailed Framework (Analytical)

### Creative Frameworks
| Framework | Example Hook |
|-----------|--------------|
| Event | "Join 5,000+ at [Name]" |
| Behind Scenes | "Revealing this for the first time..." |
| Challenge | "Think you can't do it? I dare you" |
| Transformation | "From X to Y in 72h" |

### Audience Tiers
```
WARM: Email, buyers, visitors, engagers
LAL 1%: Buyers, high-ticket, call shows
COLD: Broad + age/geo, interests
```

### Testing Process
| Step | Action | Timing |
|-------|------|--------|
| 1 | Create 5-10 concepts | D-21 |
| 2 | $100-500/day per ad set | D-14 |
| 3 | Test for 3-5 days | D-14 to D-9 |
| 4 | Measure CPP, not clicks | D-9 |
| 5 | Scale winners, kill losers | D-9+ |

### Scaling Rules
- Max 20-30% increase/week
- Monitor quality, not just volume
- Rotate creatives (fatigue)
- Add audiences gradually

---

## Patterns and Insights (Intuitive)

### Analogy
> "Ads are like fishing - first you find where the fish are (audience), then you test the bait (creatives)"

### Patterns
- Video > image, generally
- If CPR > $50, the creative or audience is bad
- Warm audience always converts better

---

## Pitfalls (Critical)

### Red Flags
- Never scale more than 30%/week
- If an ad set isn't performing after 3 days, kill it
- Don't just look at clicks, look at purchases

### Common Mistakes
```
MISTAKE: Scaling too fast
FIX: Max 20-30%/week

MISTAKE: Optimizing for clicks
FIX: Always optimize for CPP (cost per purchase)
```

---

## Variations (Creative)
- UGC (user generated content) ads
- "Day in the life" creatives
- Testimonial video hooks

---

## Key Points
- CPR target: $15-50
- Quality > quantity
- Video > image
- Retargeting is crucial
