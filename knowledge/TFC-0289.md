# Challenge Day 1 Structure

## TL;DR (Heuristic)
Day 1 (2-3h): Foundation + Community + Framework. Goal: "This is possible for me."

## Quick Guide
> Golden rule: "Day 1 = confidence and possibility. ZERO pitching."

### Day 1 Checklist
- [ ] Music and energy at the start?
- [ ] Simple, memorable framework?
- [ ] Specific homework defined?
- [ ] Anticipation for Day 2 created?

---

## Detailed Framework (Analytical)

### Schedule
```
00:00-00:15  Opening (music, energy)
00:15-00:35  Community (story, intros)
00:35-01:20  Problem agitation + reframe
01:20-02:05  Framework introduction
02:05-02:25  Homework + action items
02:25-02:45  Social proof close
```

### Content Structure
| Block | Goal | Duration |
|-------|----------|---------|
| Opening | Energy, expectations | 15 min |
| Community | "Us vs. them" | 20 min |
| Problem | Real pain, urgency | 45 min |
| Framework | Visible solution | 45 min |
| Action | Commitment | 20 min |

---

## Patterns and Insights (Intuitive)

### Analogy
> "Day 1 is like a first date - you want them thinking 'I want to see this again,' not 'will you marry me?'"

### Patterns
- If chat is quiet, run a poll/question
- If the audience drops off during the framework, it's too complex
- High engagement = high return rate on Day 2

---

## Pitfalls (Critical)

### Red Flags
- NEVER mention the product on Day 1
- If it lasts < 2h, the content is too shallow
- If the homework isn't specific, they won't do it

### Common Mistakes
```
MISTAKE: Talking about the product/offer
FIX: Focus 100% on teaching

MISTAKE: Framework too complex
FIX: 3-5 steps max, with a memorable name
```

---

## Variations (Creative)
- Pre-work before Day 1 (assessment)
- Breakout rooms for intros (smaller groups)
- "Hot seat" with a real participant

---

## Key Points
- ZERO pitching on Day 1
- Build community / "us vs. them"
- Simple, memorable framework
- End with anticipation for Day 2
