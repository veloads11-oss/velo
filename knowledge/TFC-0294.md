# Challenge Troubleshooting

## TL;DR (Heuristic)
Quick reference for common problems and immediate solutions.

## Quick Guide
> Golden rule: "If something can go wrong, it will. Have a backup."

### Emergency Checklist
- [ ] Backup Zoom ready?
- [ ] Alternative link available?
- [ ] Can the team resolve it without you?

---

## Detailed Framework (Analytical)

### Problem → Solution Matrix
| Problem | Cause | Solution |
|----------|-------|---------|
| Low registrations | Weak headline | Test new angles |
| Low registrations | Wrong audience | Refine targeting |
| Poor show rate | Weak pre-event | Add value before |
| Poor show rate | Challenge free | Consider paid |
| Low engagement | Content mismatch | Adjust level |
| Low engagement | No interaction | Add polls/chat |

### Pre-Launch Checklist
```
[ ] Zoom tested + backup link
[ ] Recording verified
[ ] Breakouts configured
[ ] Presentations final
[ ] Emails/SMS loaded
[ ] Ads performing
[ ] Team briefed
```

### Day-Of Checklist
```
[ ] T-4h: Full tech check
[ ] T-1h: Zoom live, music
[ ] T-15m: Final reminder sent
[ ] T-0: Recording started
```

## Pitfalls (Critical)

### Technical Red Flags
- If Zoom goes down, have a second link ready
- If audio fails, have a backup mic
- If the presentation gets corrupted, have a PDF backup

### Common Mistakes
```
MISTAKE: Assuming everything will go fine
FIX: Have a backup for EVERYTHING

MISTAKE: Not testing 24h beforehand
FIX: Full rehearsal is mandatory

MISTAKE: Not documenting problems
FIX: Post-mortem after every challenge
```

### Crisis Protocol
```
PROBLEM: Zoom went down
IMMEDIATE ACTION:
1. Post in chat "We're fixing it, 2 min"
2. Activate the backup link
3. Send an emergency email with the new link
4. Keep going without losing momentum
```

---

## Key Points
- Always have a backup Zoom
- Test everything 24h beforehand
- Team communication is critical
- Document problems for next time
