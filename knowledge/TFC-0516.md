# YouTube Ads and High-Impact Creatives

## TL;DR (Heuristic)
YouTube Ads = intent + long format. Strong creatives: 3-second hook + problem + solution + CTA. Test hooks, not whole videos.

## Quick Guide
> Golden rule: "The 3-second hook decides whether the rest even exists"

### YouTube Ads Checklist
- [ ] A 3-second hook that stops the scroll?
- [ ] AIDA structure (60-90 sec total)?
- [ ] 5-10 hooks to test?
- [ ] Watch rate >30% in the first 3 seconds?

---

## Detailed Framework (Analytical)

**Why YouTube Ads:**
```
ADVANTAGES:
- Intent-driven audience (actively searching)
- Long format (more warm-up)
- More qualified leads
- Higher CPL, but higher LTV

DISADVANTAGES:
- More complex production
- Slower to scale
- Higher upfront budget
```

**Video Ad Structure:**

| Phase | Time | Objective |
|------|-------|----------|
| Hook | 0-3s | Stop the scroll |
| Problem | 3-15s | Identification |
| Agitate | 15-30s | Amplify the pain |
| Solution | 30-60s | Present the way out |
| Proof | 60-90s | Credibility |
| CTA | 90s+ | Clear action |

**Hooks That Work:**
```
TYPES:
1. DIRECT QUESTION
   "Are you still [problem]?"

2. SHOCKING STATEMENT
   "I spent CAD$500K on the wrong ads..."

3. RESULT
   "[Name] made CAD$100K in 30 days..."

4. CONTRARIAN
   "Everything you learned about [X] is wrong"

5. CURIOSITY
   "The secret method that [result]..."
```

**Creative Framework:**
```
ADAPTED AIDA:

A - Attention (Hook 3s)
I - Interest (Problem 10s)
D - Desire (Solution + Proof 40s)
A - Action (CTA 10s)

Total: 60-90 seconds ideal
```

**Testing Creatives:**
```
WRONG: Testing entirely different videos
RIGHT: Testing different HOOKS on the same video

PROCESS:
1. Create 1 base video
2. Record 5-10 different hooks
3. Test the hooks
4. Scale the winner

A good hook = 30%+ watch rate in the first 3 seconds
```

**Types of Video:**
```
TALKING HEAD: Authority, connection
B-ROLL: Dynamism, professional
UGC: Authenticity, social proof
SCREEN SHARE: Tutorial, demonstration
MIXED: Combining elements
```

---

## Patterns and Insights (Intuitive)

### Analogy
> "A YouTube ad hook is like a newspaper headline - if it doesn't grab you in 3 seconds, you've lost the reader"

### Patterns
- Higher CPL but much higher LTV than Meta
- YouTube leads need less warm-up
- Talking head converts better than animation

---

## Pitfalls (Critical)

### Red Flags
- Never test whole videos at once
- Never ignore the first-3-seconds watch rate
- Never make an ad longer than 3+ minutes (it tires people out)

### Common Mistakes
```
MISTAKE: Recording 10 different videos to test
FIX: 1 base video + 10 different hooks

MISTAKE: Weak hook (watch rate <30%)
FIX: Test 5 types: question, shock, result, contrarian, curiosity

MISTAKE: Video too long (3+ min)
FIX: 60-90 seconds is ideal
```

---

## Variations (Creative)
- Mashup: talking head + screen share + b-roll
- Shocking-result hook ("CAD$500K on the wrong ads...")
- UGC-style testimonial as an ad

---

## Key Points
- YouTube = intent + long format
- The 3-second hook decides success
- Test hooks, not whole videos
- 60-90 seconds is ideal for ads
